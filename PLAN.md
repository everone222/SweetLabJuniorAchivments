# План розробки SweetLab

**Архітектура:** монолітний FastAPI-бекенд, який одночасно віддає REST API та два
статичні SPA-інтерфейси (міні-гра + адмінка). Ніяких збірок і Node.js — запуск однією
командою Python.

```
Клієнт (TMA)  ──┐
                ├──► FastAPI ──► SQLite
Адмін-панель ──┘         │
                         └──► Telegram Bot API (polling)
```
